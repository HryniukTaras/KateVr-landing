# 🎮 KateVR Landing Page

Welcome to the **landing page for KateVR** — a next-generation Virtual Reality company pushing the boundaries of immersive digital experiences. This project demonstrates a modern frontend approach using **React** and **Tailwind CSS**, combining performance, aesthetics, and responsiveness.

---

## 🚀 About the Project

KateVR’s landing page is designed to **capture attention** and **communicate innovation** from the very first scroll. With a sleek layout, smooth scroll-based animations, and dynamic visual cues, it presents the brand as futuristic and user-oriented.

From the visually striking **Hero section** to the informative **Tech Specs**, every block is crafted to reflect KateVR’s mission — to go beyond gaming and bring VR into every home, business, and imagination.

---

## 📐 Features

- ⚡️ **Responsive design** — looks great on desktop, tablet, and mobile.
- 🎨 **Animated fixed navbar** — with stylish corner transitions and smooth behavior on scroll.
- 📜 **Scroll-triggered animations** — enhance user engagement.
- 💡 **Unique section design** — including:
  - **Hero section** with bold introduction.
  - **More Than Gaming** — a look into real-world VR applications.
  - **About Us** — about company.
  - **Tech Specs** — product highlights and performance data.
  - **Contacts** — call to action with styled form.
- 🧩 **Modals** — includes:
  - **FAQ modal** with an accordion for easy navigation.
  - **Help modal** to assist users.
- 📱 **Custom slider** — a responsive slider component with:
  - **Mobile version** with swipes and touch events.
  - **Desktop version** with mouse events.
  - **Context API** for state management and slider control.

---

## 🧑‍💻 Technologies Used

- **React**
- **Tailwind CSS**
- **Material Tailwind** for Accordion component
- **HTML5 & JSX**
- **AOS (Animate On Scroll)** for scroll-triggered animations

## 📁 Project Structure

```bash
/src
  /assets # Static files like images, icons, fonts
  /components # UI components (buttons, sections, etc.)
  /shared # Reusable components (e.g. Header, Footer)
  /App.jsx # Main App component
  /input.css # Tailwind source styles
  /main.jsx  # Entry point that renders <App />
  /output.css # Compiled CSS
```

## 😎 Getting Started Locally

To run the project locally, follow these steps:

1. Clone the repository
   `git clone https://github.com/HryniukTaras/KateVr-landing.git`

2. Navigate into the project directory
   `cd KateVr-landing`

3. Install dependencies
   `npm install` or `yarn install`

4. Run the development server
   `npm run dev` or `yarn dev`

5. Open in your browser
   Usually available at: `http://localhost:5173`
